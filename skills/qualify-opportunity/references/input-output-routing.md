# Input And Output Routing

Inventory each input's kind, locator, date, owner, permission and accessible
body. Deduplicate repeated exports and summaries. A link, filename or existing
record does not prove its contents were read. Preserve conflicts unless an
authoritative source resolves them.

| Input lane | Qualification use | Evidence ceiling |
| --- | --- | --- |
| Sparse relationship or enquiry | Confirm the concrete problem, desired result, known people and commitment; name gaps | A company-only lead needs a clarifying question, not an empty report; an introduction does not qualify an end customer |
| Completed meeting notes | Carry confirmed decisions, commitments, roles, offered evidence and changed gaps into the assessment | Keep the dated meeting snapshot in Meetings; preparation and tentative discussion are not outcomes |
| Data or technical evidence | Establish identity, coverage, units, observation scope, missingness and validation before analysis | Calculate only from authorized accessible bytes or a verified analysis; samples do not prove production performance, causality or value |
| Proposal, report or requirements | Separate facts, requirements, proposed scope, assumptions and contractual commitments | Review rights, effort, dependencies, acceptance and authority; assertions are not proof of delivery or buyer approval |
| Mixed refresh | Reconcile all included lanes and superseded state | Retain unresolved conflicts as gaps; summaries cannot overrule authoritative evidence |

**Chat:** return the shared core briefly and name the next evidence question.
The draft is unsaved; no artifact, task or CRM write follows automatically.

**Engagement assessment child page:** update one current record in place using
the core, with conditional sections only when they change the decision. Search
and fetch the Engagement and its existing child pages first. Workspace is for
reusable organizational knowledge, not engagement-specific assessments. A
draft is still possible when child-page creation or parent identity is unavailable.
Ambiguous duplicates or missing identity block that write;
the draft can continue. Read back identity, populated content, one gaps register,
verdict, links and separately configured properties/correlation metadata.

**Proposal review:** use the same core plus relevant commercial/technical
sections in the requested review surface. This does not automatically copy
them into a canonical page or authorize an offer.

The ordinary manual Meeting template remains usable without an agent. Meeting
Runner synthesis retains exactly one table with the three columns `Topic`,
`Outcome / Decision`, `Actions`. Never place the assessment's gaps register, preparation,
agenda or technical analysis inside that meeting table. Link the assessment
when permitted; refresh its durable state only within requested authority.
