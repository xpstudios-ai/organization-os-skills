# Meeting Records: Draft Only

No persistent preparation or post-meeting destination is configured.
`workflow.meeting_records = "draft-only"` explicitly selects this limitation.

## Preparation Destination

Return the complete pre-call brief in chat. Search supplied context for the
exact meeting identity and prior preparation; do not invent a folder or account.

## Post-Meeting Destination

Return the complete synthesis in chat, separate from preparation. Preserve
distinct topics, decisions, accountable actions, owners, known dates, and links.

## Publication

This route permits no file, tracker, CRM, or external document writes. An exact
user-supplied destination and separately authorized mutation can supply a
per-run adapter; verify identity and access, preserve existing content, and
read back any write. Otherwise deliver the draft with the missing destination.

Persistent routing is enabled only after the destination is configured.
