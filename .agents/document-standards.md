# Documentation Standards

README explains selection, setup and local installation; CONTRACT owns package
workflow boundaries. Skill resources own reusable output formats. Catalog owns
resource/provenance metadata. NOTICE owns attribution and publication caveats.
`docs/ALIGNMENT.md` owns the bounded catalog assessment and outstanding gates.
Keep detailed test receipts and private comparison evidence in the local task,
not in reusable guides or public skill prose.

Sweep changed names, dependency bundles, counts, metadata and source ownership
for stale references. Preserve Meeting Runner's manual/default outcome contract
and meeting-first adoption. Maintain these overlays only for durable rules;
avoid copying the entire originating request. External/template/website writes
require their owning scope and readback and are outside this local candidate.
