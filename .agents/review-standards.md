# Review Standards

Review the stable candidate directly in the originating task along Standards
and Spec axes. Inspect all task changes and untracked resources. Bind the
verdict to a commit or source/diff digest. Any semantic mutation requires a
fresh verdict on the updated candidate.

Require package validation, tests, diff hygiene, complete shared-kernel parity,
dependency closure, sensitive-content and license/provenance assessment, and
clean-consumer installation/scenario checks. Review installer preflight and
rollback, metadata-policy agreement, evidence ceilings and external-write
failure paths explicitly. Report any untested live or cross-platform paths.

Source readiness and publication clearance are separate. Pending resource
rights do not authorize publishing. Record exact hosted checks for their actual
head; no candidate hosted run exists until the candidate is submitted. Hosted
capacity failure alone does not block otherwise passing authorized source work.
